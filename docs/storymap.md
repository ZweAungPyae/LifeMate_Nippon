# 留学生向け日本生活ガイド

1. アクティビティ
2. タスク
3. ウォーキングスケルトン
4. リマインド対応(v1.0)
5. 専用アプリの追加通知機能(v2.0)

- アプリを開く #留学生
  - ホーム画面を見る
    - [ ] ゴミの分別
      - 燃えるゴミ、資源ゴミなどを説明する。
        - 日にちによってゴミを捨てる種類をcalenderで確認できる
- 情報を探す
  - [x] 情報を選ぶ
    - 交通機関を選ぶ
      - 電車やバスのスケジュールを確認できる
      - アルバイト募集情報
        - アルバイト応募できる
- 情報を確認する
  - 色々な言語で確認できる
    - アルバイトのルールを学ぶ
      - ビジネスマナー
        - 知りたい日本語を通訳できる
- 情報を理解する
  - 優しい日本語で説明する
    - アルバイトでよく使う日本語
    - 日常生活でよく使う日本語
      - 病院で使う日本語
      - 買い物するとき使う日本語
        - 情報を音声で教えてくれる
        - キーワードで情報を検索する
- 行動する  
  - 必要な手続きを教えてくれる  
     - 生活ガイド
       - 民登録や健康保険などを説明する
